# Pushover Notifications

> An unofficial, community-made extension for [Prusa Connect](https://github.com/prusa3d/prusa-connect).
> Not made, endorsed or supported by Prusa Research.

Sends a [Pushover](https://pushover.net) notification when a print starts, reaches a progress checkpoint, finishes or fails.

**Status: planning.** There is no code yet. See [DESIGN.md](DESIGN.md).
